Font Pocket 0.1.0 · 폰트 포켓
첫 공개 릴리스입니다. 개발 중 사용한 3.x 버전 번호를 공개 배포용 0.1.0으로 정리했습니다.

공식 GitHub 저장소 tae0604/font-pocket에서만 앱 업데이트를 확인합니다.
사용자 주소 입력칸을 제거하고, 예전 설정의 임의 저장소 주소도 무시합니다.
공식 배포처가 아닌 다운로드 주소는 거부합니다.

3.1.18 설치 언어 선택창 수정
Windows 표시 언어가 한국어면 한국어, 그 외 언어면 English를 기본 선택합니다.
선택을 바꾸면 제목·안내·확인·취소 버튼의 언어도 즉시 함께 바뀝니다.
이전 설치 언어보다 PC의 현재 표시 언어를 우선하며, 자동 업데이트의 명시적 언어는 유지합니다.

3.1.17 GitHub 앱 업데이트 및 언어 설정
왼쪽 아래 업데이트에서 GitHub 저장소를 설정하고 새 정식 릴리스를 확인합니다.
하루 한 번 자동 확인, 수동 확인, SHA-256 검증 후 다운로드·설치·재실행을 지원합니다.
저장소는 아직 미연결 상태이며 공개 릴리스의 버전별 EXE와 .sha256 파일을 사용합니다.
설치 첫 화면에서 한국어 / English를 선택합니다. 앱의 언어 버튼에서도 바꿀 수 있습니다.
앱 언어 변경은 재실행 후 적용됩니다.

3.1.16 설치 완료 화면 로고 변경
설치 마법사 왼쪽의 기본 디스크 그림을 Font Pocket 폴더 로고로 교체했습니다.
로고를 가운데에 배치하고 사방 여백을 확보했습니다.

3.1.15 선택 방법 안내 보완
클릭: 한 개 선택 · Ctrl+클릭: 개별 추가·해제 · Shift+클릭: 연속 범위 선택
목록 위에 안내를 별도 줄로 표시합니다.

3.1.14 폰트 관리의 선택 방식 통일
폰트 관리 목록의 체크박스를 없애고 강조된 행을 작업 대상으로 사용합니다.
클릭하면 한 개 선택, Ctrl+클릭하면 개별 추가·해제, Shift+클릭하면 마지막으로 선택한 항목부터 클릭한 항목까지 연속 범위를 선택합니다. Ctrl+A로 전체 선택, Esc로 선택을 해제합니다.
검색·필터로 숨겨진 항목은 작업 대상에서 제외됩니다. 선택한 개수를 목록 위에 표시합니다.
설치 대기열과 백업 목록의 선택 방식은 기존대로 유지됩니다.

3.1.13 즐겨찾기 분리 및 기본 UI 정리
더 보기·우클릭 메뉴에서 즐겨찾기를 바로 추가하거나 해제합니다. 체크 표시는 등록 상태입니다.
메모·태그 창에서 즐겨찾기를 분리했으며 기존 즐겨찾기 데이터는 유지됩니다.
상세 정보 탭을 Windows 기본 탭으로 변경하고, 검색창을 이전의 기본 입력창으로 되돌렸습니다.

3.1.12 검색창 레이아웃 및 디자인 수정
검색창의 아래쪽 테두리가 잘리고 필터 줄과 붙던 높이 계산을 수정했습니다.
옅은 둥근 테두리, 안쪽 여백과 포커스 표시를 적용했으며 입력은 Windows 기본 편집 컨트롤을 사용합니다.
새로고침 버튼과 검색창의 높이를 맞췄습니다. 작업 버튼은 Windows 기본 스타일을 유지합니다.

3.1.11 Windows 기본 작업 버튼과 검색창 정리
작업 버튼과 대화상자 버튼을 Windows 기본 컨트롤로 변경했습니다.
검색창 안쪽 여백과 새로고침 버튼의 높이를 맞췄습니다.
버튼 활성화 조건, 키보드 조작 및 툴팁은 유지합니다.

3.1.10 패밀리 표시와 굵기 정렬
상세 정보에 타이포그래픽 패밀리·스타일을 표시하며 Windows 호환 이름도 보존합니다.
상세 정보 위 목록에서 같은 패밀리의 다른 폰트 파일로 전환할 수 있습니다.
관리 목록·전체 견본·상세 목록은 패밀리별 실제 굵기 값의 오름차순으로 정렬합니다.
파일 검사 후 상태가 검사 중으로 남는 표시를 수정했습니다.

3.1.9 폰트 미리보기 수정
견본·비교·개별 미리보기에서 폰트 전환 후 다른 글꼴이 표시되는 문제를 수정했습니다.
미리보기 전용 파일 로딩을 사용해 반복 전환과 캐시 교체 시 글꼴 연결을 유지합니다.

3.1.8 사이드바 로고 크기 조정
아이콘과 Font Pocket 제목을 같은 비율로 약 10% 줄였습니다.
Pretendard SemiBold와 넉넉한 오른쪽 여백을 유지합니다.

3.1.7 사이드바 간격 및 글꼴 조정
제목을 Pretendard SemiBold로 변경하고 아이콘과 글자 사이의 간격을 넓혔습니다.
사이드바 오른쪽에는 아이콘과 글자 사이보다 넉넉한 여백을 두었습니다.

3.1.6 사이드바 로고 비율 조정
첨부한 로고 시안에 맞춰 아이콘과 Pretendard 제목의 실제 윤곽을 정렬했습니다.
아이콘과 제목 사이의 간격을 줄이고 높이 비율과 아래쪽 기준선을 맞췄습니다.

3.1.5 로고 및 제목 정리
수정한 SVG를 앱과 설치 파일 아이콘에 적용했습니다.
사이드바 제목은 Pretendard Bold로 키웠으며 앱 안에서만 글꼴을 불러옵니다.
설치 마법사의 오른쪽 로고에 여백을 추가했습니다.

3.1.4 새 로고
폴더 모양의 새 로고를 앱·작업 표시줄·시작 메뉴·바탕화면·설치 파일에 적용했습니다.
앱의 각 창과 사이드바에도 같은 로고를 표시합니다.

3.1.3 Windows 기본 인쇄 미리보기
더 보기 → 견본·문자표 인쇄 / PDF에서 견본 종류를 선택하고 인쇄를 누르세요.
Windows 기본 인쇄 창 안에 실제 폰트 견본과 문자표가 표시됩니다.
페이지 이동·확대·방향·용지 설정은 Windows 인쇄 창에서 변경합니다.
Microsoft Print to PDF를 선택하면 PDF로 저장할 수 있습니다.
기본 창에서 인쇄를 누르기 전까지 실제 출력되지는 않습니다.
한 번에 300쪽까지 지원하며, 많은 문자표는 폰트를 나누어 인쇄하세요.
Windows 10 버전 1903 이상 또는 Windows 11이 필요합니다.

3.1.1 버튼 상태와 도움말
폰트 관리·다운로드·백업 화면의 버튼은 선택과 작업 조건에 맞춰 켜집니다.
활성화는 내 계정의 비활성 폰트, 비활성화는 내 계정의 활성 폰트에만 켜집니다.
비교는 2~12개를 선택하거나 체크했을 때 사용할 수 있습니다.
체크한 폰트가 있으면 체크한 폰트를 먼저 작업 대상으로 사용합니다.
삭제와 선택 백업은 체크한 폰트를 대상으로 합니다.
버튼 위에 마우스를 잠시 올리면 기능 설명과 사용할 수 없는 이유가 표시됩니다.
더 보기 메뉴와 목록의 마우스 오른쪽 메뉴에도 같은 조건을 적용합니다.

설치하기
FontPocket-Setup-3.1.6.exe를 실행하고 설치를 진행하세요.
설치 후 시작 메뉴에서 Font Pocket을 검색해 실행할 수 있습니다.
바탕화면 바로가기는 설치 중 선택할 수 있습니다.
기본 설치 위치: %LOCALAPPDATA%\Programs\Font Pocket
관리자 권한 없이 현재 계정에 설치됩니다.
다음 버전도 같은 설치 파일을 실행하면 기존 위치에 업데이트됩니다.
제거: Windows 설정 → 앱 → 설치된 앱 → Font Pocket → 제거
제거하거나 업데이트해도 설치한 폰트와 개인 데이터·백업은 유지됩니다.
기존 FontPocket.exe로 저장한 메모·태그·모음도 그대로 사용합니다.
설치 없이 사용하려면 기존 FontPocket.exe를 직접 실행해도 됩니다.

3.1 점검 및 화면 정리
모든 주요 창의 글꼴·색상·입력창·목록·버튼 간격을 통일했습니다.
큰 견본 잘림, 격자 스크롤 배치 반복, 필터 후 남는 미리보기,
빠른 검색 상세 창 순서와 체크 상태 보존을 수정했습니다.
설치 실패 복원과 백업·환경 복원의 파일 내용 검사를 보강했습니다.
관리 화면의 큰 미리보기는 스크롤로 확인할 수 있습니다.
검사 범위와 한계는 함께 제공한 검사 결과 문서에 정리했습니다.
시작하기
FontPocket.exe를 실행하면 폰트 관리 화면이 열립니다.
현재 계정용 폰트를 기본 표시하며 시스템 / 모든 사용자용 폰트는 보호합니다.
검색에는 이름·파일명·형식·버전과 개인 메모·태그가 함께 반영됩니다.

3.0의 새 기능
- 상단 중복 정리: 검색 → 그룹별 남길 폰트 선택 → 확인 후 정리를 한 흐름으로 통합
- 상세 정보: 미리보기 / 문자표 / 지원 언어·문자 범위 / 정보 / 검사
- 전체 폰트 견본: 문장 견본 / 두 열 / 격자 / 패밀리 순서
- 버전 보관·비교·전환 및 실패 시 기존 등록 복원
- 빠른 검색: 앱 안에서 Ctrl+K, 앱 실행 중 Ctrl+Alt+Space
- 메모·태그·즐겨찾기, 일반 모음과 조건에 따른 자동 모음
- 패밀리로 묶기, 파일 검사, 견본·문자표 인쇄 / PDF
- 개인 정보·모음·활성 상태·보관 버전까지 환경 백업과 복원

폰트 관리
행을 선택하면 아래에서 실제 파일의 글꼴로 미리 봅니다.
상단 상세 정보 버튼 또는 행 더블클릭으로 상세 정보를 엽니다.
체크가 있으면 일괄 작업에는 체크한 항목을 사용합니다.
활성 상태 전환·비교·검사는 체크가 없으면 선택한 행을 사용합니다.
체크는 검색으로 숨겨져도 유지됩니다. 작업 전 대상 개수를 확인하세요.
선택 백업 / 선택 삭제 / 선택 해제 / 복원은 더 보기 메뉴에 있습니다.
우클릭 메뉴에도 상세 정보·메모·버전 관리·파일 위치·표시 항목 체크가 있습니다.

상세 정보와 문자표
- 문자 수는 Unicode 매핑에서 글리프가 존재하는 코드 포인트의 개수입니다.
- 글리프 수는 maxp 테이블 기준이며 문자 수와 다를 수 있습니다.
- TTC는 위 서체 목록에서 각각의 정보와 문자 매핑을 읽습니다.
  미리보기 엔진에서 해당 패밀리를 찾지 못하면 지원하지 않는다고 표시합니다.
- 문자표는 문자 또는 U+AC00 같은 코드로 검색하고 범위별로 필터할 수 있습니다.
  제어 문자는 기본으로 숨깁니다. 원하는 문자를 클릭하고 문자 복사를 누르세요.
- 지원 범위는 실제 매핑 기준의 포함 / 기준 개수입니다.
  한글 완성형은 11,172자를 기준으로 하고 자모·옛한글은 따로 표시합니다.
  문자 집합 충족은 언어 전체 지원을 보장하지 않습니다. 조합·문맥 처리는 별도입니다.
- 이름·스타일·버전·제작사·디자이너·설명·저작권·라이선스·URL·위치를 볼 수 있습니다.
  파일에 기록이 없으면 정보 없음으로 표시하며 사용 허용 범위를 자동 단정하지 않습니다.
- 검사 탭은 테이블 범위·문자 매핑·체크섬·Windows 메모리 로드를 확인합니다.
  전체 서체 검사는 관리 화면의 더 보기 → 폰트 파일 검사를 사용하세요.
  모든 렌더링 문제나 악성 코드를 검사하는 기능은 아닙니다.

가변 폰트
상세 정보의 가변 축 조절 버튼으로 기본 브라우저에 로컬 미리보기를 엽니다.
실제 fvar 축의 최소 / 기본 / 최댓값으로 굵기·너비 등의 슬라이더를 만듭니다.
폰트 데이터가 문서에 포함되어 별도 서버나 설치가 필요하지 않습니다.
현대적인 브라우저가 필요하며 TTC의 가변 축 조절은 지원하지 않습니다.
브라우저 문서는 개인 데이터 폴더의 Previews에 저장됩니다.

전체 폰트 견본
견본 보기는 현재 필터에 맞는 폰트를 함께 표시합니다.
문구·크기를 바꾸고 문장 / 두 열 / 격자 / 패밀리 순서로 둘러볼 수 있습니다.
화면에 보이는 폰트 위주로 읽으며 전체를 동시에 메모리에 로드하지 않습니다.
견본을 더블클릭하면 상세 정보를 엽니다.
관리 목록 자체를 묶으려면 더 보기 → 패밀리로 묶기를 사용하세요.

메모·태그·즐겨찾기·모음
폰트를 선택하고 더 보기 또는 우클릭 → 메모·태그·즐겨찾기를 여세요.
태그는 쉼표로 구분합니다. 메모와 태그는 관리 화면과 빠른 검색에서 검색됩니다.
즐겨찾기는 별표로 표시하며 모음 선택창에서 따로 볼 수 있습니다.
더 보기 → 모음 관리에서 일반 / 자동 모음을 생성·수정·삭제합니다.
일반 모음 생성 시 현재 체크하거나 선택한 폰트를 함께 담습니다.
기존 모음에 추가 / 해제하려면 각 폰트의 메모 창에서 모음을 체크하세요.
자동 모음 조건은 이름·태그·TTF·OTF·활성·비활성·가변 등입니다.
여러 조건은 ; 로 구분해 모두 만족시킵니다. 예: 본문;TTF;활성
모음 삭제는 폰트 파일을 삭제하지 않습니다.
현재 모음 활성화 / 비활성화는 필터로 표시되는 해당 모음 대상에 적용합니다.

활성화와 비활성화
현재 계정 폰트만 전환하며 시스템 폰트는 보호합니다.
비활성화 시 원본을 보존하고 사본과 등록 정보를 따로 보관합니다.
재실행해도 상태가 유지됩니다. 개인 데이터의 Disabled 폴더를 지우지 마세요.
비활성 표시는 활성·비활성을 함께, 비활성만은 비활성 폰트만 표시합니다.
비활성만과 중복만은 동시에 사용하지 않습니다.
열려 있는 앱에는 앱 재실행 또는 Windows 재로그인 후 반영될 수 있습니다.

중복 정리
상단 중복 정리를 누르면 검색과 그룹 검토가 이어집니다.
내용이 같은 파일은 SHA-256으로, 이름·스타일 겹침은 별도 후보로 구분합니다.
완전 동일한 그룹만 기본 체크하며 형식·버전이 다른 그룹은 직접 확인해야 합니다.
그룹 더블클릭 / 남길 폰트 변경으로 남길 파일을 선택할 수 있습니다.
다른 굵기와 정적 / 가변 폰트는 같은 스타일로 합치지 않습니다.
삭제 전 복구 ZIP을 저장하며 백업 실패 시 삭제하지 않습니다.
글자 데이터를 합쳐 새 폰트를 만드는 기능은 아닙니다.
중복만 필터는 중복 정리에서 검색한 결과를 기준으로 표시합니다.

폰트 버전 관리
폰트를 선택하고 버전 관리를 열면 해당 설치 / 비활성 버전을 보관합니다.
버전 파일 추가로 TTF / OTF / TTC / ZIP의 다른 버전을 보관할 수 있습니다.
선택한 글꼴과 스타일이 같은 버전들을 모아 보여 줍니다.
모든 보관 파일은 더 보기 → 버전 보관함 · 미설치 파일에서 볼 수 있습니다.
같은 버전 문자열이어도 내용이 다르면 SHA-256으로 구별해 각각 보관합니다.
선택한 버전들을 비교하고 이 버전 사용으로 다른 내 계정 버전을 비활성화합니다.
원래 버전은 보관하며 전환 실패 시 원래 등록 복원을 시도합니다.
같은 글꼴의 시스템 버전은 자동 교체하지 않습니다.
버전 번호만으로 최신 여부를 단정하거나 자동 업데이트하지 않습니다.
다운로드 화면에서 설치를 누른 파일과 기존 같은 스타일은 버전 원본도 보관합니다.
이미 같은 스타일이 활성 상태이면 기존 글꼴을 유지하고 새 버전은 보관만 합니다.
설치 전 보관만 하려면 체크하고 우클릭 → 체크한 파일 버전으로 보관을 사용하세요.
버전 보관에는 폰트 원본을 저장하므로 디스크 용량을 사용합니다.

빠른 검색
앱 안에서는 Ctrl+K, 앱 실행 중에는 Ctrl+Alt+Space를 누르세요.
이름·버전·형식·메모·태그로 찾아 상세 정보나 관리 화면으로 이동합니다.
내 계정 폰트의 활성 상태도 전환할 수 있습니다. Escape로 닫습니다.
다른 앱이 단축키를 사용 중이면 작업 기록에 표시하며 Ctrl+K는 계속 사용할 수 있습니다.
프로그램이 종료된 상태에서는 단축키가 동작하지 않습니다.

다운로드와 설치 전 확인
눈누 상세 페이지·공식 사이트·직접 ZIP / 폰트 HTTPS 주소를 붙여넣으세요.
여러 주소는 줄바꿈으로 넣으며 한 번에 최대 30개입니다.
대기열에 추가는 파일만 받고 바로 설치는 선택된 파일을 설치합니다.
공개 페이지를 최대 3단계 / 12개까지 따라갑니다. 관련 페이지를 직접 고를 수도 있습니다.
로그인·캡차·구매·동의 입력·JavaScript 다운로드는 직접 진행해야 할 수 있습니다.
파일 · ZIP 추가 / 폴더 추가 / 끌어놓기도 지원합니다.
TTF만 / OTF만 / 둘 다 및 TTC 포함 설정은 ZIP·폴더·링크에 공통 적용됩니다.
다른 형식을 체크하면 해당 파일도 선택할지 확인합니다.
WOFF / WOFF2 웹폰트와 macOS의 ._ 리소스 파일은 제외합니다.
정적 / 가변 다운로드를 구분하고 실제 fvar 정보도 읽습니다.
대기열에서 더블클릭 / 미리보기 / 상세 정보를 사용할 수 있습니다.
비교는 최대 12개 / 합계 256MB까지이며 설치·활성화 없이 메모리에서 읽습니다.
개별 미리보기는 최대 128MB입니다. 기본 TTC 비교는 첫 번째 서체를 표시합니다.

삭제와 복원
내 계정 폰트를 체크하고 더 보기 → 선택 삭제를 사용하세요.
시스템 폰트를 보호하며 삭제 전 복구 ZIP을 자동 저장합니다.
계정 등록을 해제하며 현재 계정의 Windows Fonts 폴더 안에 있는 파일만 삭제합니다.
다른 위치의 원본이나 사용 중인 파일은 남을 수 있습니다.
복구 ZIP: %LOCALAPPDATA%\FontPocket\Removed
더 보기 → 삭제 폰트 복원으로 ZIP을 대기열에 넣고 확인 후 설치하세요.

폰트 백업과 환경 백업
왼쪽 백업은 Windows에 등록된 폰트 중 원하는 항목을 ZIP으로 저장합니다.
검색으로 숨겨져도 체크한 항목은 백업 대상입니다.
비활성 폰트는 관리 화면의 선택 백업 또는 환경 백업을 사용하세요.
더 보기 → 환경 백업은 내 계정 활성 / 비활성 폰트, 보관 버전,
메모·태그·즐겨찾기·모음·활성 상태를 하나의 ZIP으로 저장합니다.
환경 복원은 폰트 전체의 무결성을 검사한 뒤 시작합니다.
기존 메모·모음·설치 상태를 유지하고 없는 항목을 추가합니다.
다른 버전이 이미 활성 상태이면 받은 버전은 보관만 합니다.
중단 / 일부 실패 시 완료한 항목은 유지하며 자세한 결과는 작업 기록에 표시합니다.

인쇄 / PDF와 운영체제 기능
더 보기 → 견본·문자표 인쇄 / PDF에서 목록 / 여러 크기 / 전체 문자표를 선택하세요.
인쇄 창에서 Microsoft Print to PDF를 선택하면 PDF로 저장합니다.
TTC 인쇄는 첫 번째 서체를 사용합니다.
더 보기 → Windows 글꼴 설정에서 운영체제의 스토어·언어 추가 등으로 이동합니다.
macOS 전용 폰트 다운로드나 macOS 시스템 복원은 Windows에서 수행하지 않습니다.
이 앱의 직접 설치·전환·삭제는 현재 계정 기준입니다.

저장 위치와 제한
설치: %LOCALAPPDATA%\Microsoft\Windows\Fonts
개인 정보: %LOCALAPPDATA%\FontPocket\library.json
비활성 보관: %LOCALAPPDATA%\FontPocket\Disabled
버전 보관: %LOCALAPPDATA%\FontPocket\Versions
앱을 지워도 설치한 폰트와 개인 보관 데이터는 남습니다.
ZIP 안의 ZIP·암호 ZIP은 지원하지 않습니다.
다운로드 최대 1GB / ZIP당 10,000개 / 폰트 512MB / 압축 해제 총 2GB입니다.
환경 백업도 최대 10,000개 / 총 2GB까지입니다.
Unicode cmap 0 / 4 / 6 / 12 / 13을 읽으며 다른 형식은 판정 불가로 표시합니다.
컬러·가변·특수 폰트는 미리보기 엔진에 따라 표시가 제한될 수 있습니다.

검증
실제 폰트 327개의 문자 매핑과 글리프 수가 Windows WPF 엔진 결과와 일치했습니다.
상세·문자표·지원 범위·견본·메모·빠른 검색·버전 관리와 최소 창 크기를 확인했습니다.
버전 전환 실패 복원·시스템 보호·상태 유지 검사는 격리된 등록 저장소에서 수행했습니다.
개인 정보·모음 저장과 환경 ZIP 왕복, 변조된 파일 거절을 검사했습니다.
실제 설치 폰트의 등록·활성 상태를 바꾸는 검사는 수행하지 않았습니다.
다른 Windows PC·인쇄 장치·모든 폰트 / 사이트까지 검사한 것은 아닙니다.
