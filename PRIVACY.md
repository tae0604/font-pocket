# Privacy policy

Font Pocket stores font metadata, favorites, notes, tags, collections, settings,
and operation history locally on your computer. Backup/export features write to
the location you choose. There is no application account, advertising SDK, or
analytics upload in the published application source.

## Network connections

- Font downloads contact the font websites, download hosts, and any redirects
  involved in the download you request. This may include Noonnu and GitHub.
- Update checks contact GitHub for `tae0604/font-pocket`. Automatic checks are
  enabled by default and run at most once per day on startup. Disable them using
  the automatic-check checkbox in the app's Settings window and save the setting.
- Installing an update downloads the installer from this repository's GitHub
  release assets after you choose to install it.
- Network providers receive normal request information such as your IP address
  and user agent. Font Pocket does not upload your font collection, notes, tags,
  backups, or operation history as part of these requests.
- Opening a website or sharing an issue manually follows your browser's settings.
  Do not attach personal logs or backup files to public issues without reviewing them.

Third-party services apply their own policies:
[GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement),
[Noonnu](https://noonnu.cc/), and any font provider you access.
Check each provider's published privacy terms before using its service.
The bundled Pretendard font makes no network requests.

## 한국어

폰트 정보, 즐겨찾기, 메모·태그, 모음, 설정과 작업 기록은 PC에 저장합니다.
다운로드 시 요청한 폰트 사이트와 다운로드 서버에 접속하며, 업데이트 확인 시
GitHub 공식 저장소에 접속합니다. 자동 업데이트 확인은 기본으로 켜져 있고
시작 시 하루 한 번 이하로 실행합니다. 앱의 설정에서 자동 확인을 끄고
설정을 저장할 수 있습니다. 서비스 제공자는 IP 주소·사용자 에이전트 등 통상적인
요청 정보를 받을 수 있습니다. 앱은 이 요청에 폰트 목록·메모·태그·백업·작업 기록을
업로드하지 않습니다. 이용하는 사이트의 개인정보 처리방침도 함께 적용됩니다.
