# Font Pocket

폰트를 내려받고, 설치하고, 관리합니다.

Windows용 폰트 관리 프로그램입니다. 눈누·공식 사이트의 링크나 ZIP 파일에서 폰트를 가져오고, 설치된 폰트를 한곳에서 관리할 수 있습니다.

## 다운로드

[최신 설치 파일 받기](https://github.com/tae0604/font-pocket/releases/latest)

릴리스의 **FontPocket-Setup-버전.exe**를 실행하세요. 설치할 때 한국어 또는 English를 선택할 수 있습니다.

- Windows 10 / 11 · .NET Framework 4.8 이상
- 현재 Windows 계정에 설치
- 앱의 **언어 / Language**에서 언어 변경 가능 — 재실행 후 적용

## 주요 기능

- 눈누·공식 사이트·다운로드 링크에서 폰트 가져오기
- ZIP·폴더에서 TTF, OTF, TTC 선택 및 설치
- 설치 전 미리보기, 여러 폰트 비교, 전체 폰트 견본
- 폰트 활성화·비활성화, 중복 확인·정리
- 문자표, 지원 문자 범위, 제작자 및 폰트 상세 정보
- 선택 백업·복원, 폰트 버전 보관
- 즐겨찾기, 메모, 태그, 모음, 빠른 검색
- 폰트 견본·문자표 인쇄 및 PDF 저장

## 업데이트

앱 왼쪽 아래 **업데이트 / Updates**에서 새 버전을 확인할 수 있습니다. 시작할 때 하루 한 번 자동 확인하도록 설정할 수도 있습니다.

업데이트는 이 공식 저장소의 정식 릴리스에서만 받습니다. 설치 파일의 크기와 SHA-256을 확인한 뒤, 사용자가 설치를 선택하면 업데이트합니다. 설치된 폰트와 개인 설정은 유지됩니다.

## English

Font Pocket is a Windows font manager for downloading, previewing, installing, organizing and backing up fonts. Korean and English are available in Setup and in the app.

Download the installer from [Releases](https://github.com/tae0604/font-pocket/releases/latest). App updates are restricted to this official repository.
